Project Charter · Core Banking Migration
Project Charter · v1.2 · Approved Apr 2026 Approved by Steerco

Migrate Riverton Financial's core banking platform from Symitar to FIS Code Connect over 18 months.

$84M total program. Wave 1 (deposits + treasury) cuts over Q2 2027; Wave 2 (lending) Q4 2027; Wave 3 (treasury services) Q2 2028. Hypercare runs 90 days post each wave.

Objectives

  • Modernize core platform — replace Symitar (end-of-life FY28) with FIS Code Connect cloud-native core.
  • Reduce IT operating cost by $5.4M annually — sunset 6 ancillary systems wrapped around legacy core.
  • Enable next-gen products — instant-issue debit, real-time fraud, embedded banking APIs.
  • Maintain regulatory standing — SOC 1 Type II + FFIEC parity throughout migration.

Scope

In scope

  • Deposit accounts (consumer + commercial)
  • Loans (consumer, mortgage, commercial)
  • Treasury services (wires, ACH, lockbox)
  • Card issuance + processing migration
  • Online + mobile banking re-platform
  • Branch teller workflows

Out of scope

  • Trust + wealth management platform (separate program)
  • Marketing CRM (Salesforce stays)
  • HRIS / payroll (Workday stays)
  • Compliance reporting (Riverton-built; integrate via API)
  • ATM hardware refresh (in flight, parallel)

Risks & assumptions

Top 5 risks

  • Vendor execution. FIS team continuity through 18-month engagement; backstop: 3-person vendor advisory partner contracted.
  • Customer impact during cutover. Branch + digital downtime <6 hrs target; rollback drilled.
  • Data migration completeness. 8.4M customer records, 62M transactions; 3-pass cleanse + reconcile.
  • Regulatory exam during migration. Compliance attestation pre-cutover; mock exam Q1 2027.
  • Talent retention. Key Riverton SMEs at retention risk; retention bonuses approved.

Assumptions

  • Symitar EOL stays at FY28; no extension push from vendor.
  • FFIEC posture unchanged through migration window.
  • No M&A activity that would alter scope mid-program.
  • Card processor contract aligns to Wave 2 cutover dates.
  • Riverton can dedicate 14 SMEs at >50% allocation throughout.
